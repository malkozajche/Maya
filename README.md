# Maya · Termen-Abenteuer

A cute, gamified practice page for **order of operations with fractions** (Punkt vor Strich, Klammern, Potenzen) — the skill from Maya’s textbook exercises (e.g. `¾ − ¾ · (⅚ + ½)` and Aufgabe 4 „Berechne“).

## Play (public page)

**https://malkozajche.github.io/Maya/**

**Streichholz-Terme (Variable):** https://malkozajche.github.io/Maya/streichholz.html

**Französisch · Nice (hören und nachsprechen):** https://malkozajche.github.io/Maya/francais.html

## How it works

1. Pick a level (Sanft / Mutig / Sternenflug)
2. Choose the **first correct step** (Klammer → Potenz → Punkt → Strich)
3. Enter the final answer as a fraction
4. Collect stars — hints available anytime

## Französisch

Der Bilan zu Nizza (Parler, Vokabeln, direktes und indirektes Objekt, Adjektive, *voir*) ist ein eigener Test. Jeder Lösungssatz wird auf Französisch vorgesprochen. Mit Mikrofon vergleicht die Seite das Nachsprechen mit der Lösung, speichert aber keine Aufnahme.
